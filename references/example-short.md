## 题意简述

在周长为 $N$ 的毛衣上尽量多地织出长度为 $P$ 的完整图案。正面中央已经有一个图案，其余图案要保持左右对称。空白只能在背面连成一段。求最少留下多少针空白。

## 思路

有空白时，先看这一段空白的位置。左右翻转后，它作为唯一的空白段必须和自己重合，所以段的中央在对称轴上。正面中央已经织了图案，这段空白只能以背面中央为中心。此时，除去正面中央的图案，其余图案都在翻转中两两对应。若还有一个图案翻转后保持原位，它就必须在背面中央，会占据空白段的中央。

因此，在留有空白的方案里，增加图案要以一对为单位。扣掉正面图案后还有 $N-P$ 针，每一对占 $2P$ 针。把图案紧挨着正面图案向两侧成对铺开，能铺满 $\lfloor (N-P)/(2P)\rfloor$ 对。剩下的 $r=(N-P)\bmod(2P)$ 针在背面连成一段。这也给出了留有空白时的覆盖上限，因为再加一对就超过了周长。

结果还可能是完全铺满。此时 $N$ 必须是 $P$ 的倍数，所以 $r$ 只能是 $0$ 或 $P$。若 $r=0$，刚才成对铺完就已覆盖整圈。若 $r=P$，背面恰好能再放一个图案，它以背面中央为中心，填完后仍然对称。其他余数无法铺满，保留长度为 $r$ 的一段空白即可。

## 复杂度分析

时间复杂度和空间复杂度均为 $O(1)$。数据上界为 $10^{18}$，计算余数所用的 $2P$ 可以用有符号 64 位整数保存。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n, p;
    cin >> n >> p;
    // 扣掉正面中央的图案，按一对图案的长度取余。
    const long long rest = (n - p) % (2 * p);
    cout << (rest == p ? 0 : rest) << '\n';
    return 0;
}
```
