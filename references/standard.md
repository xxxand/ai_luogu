# 洛谷主题库题解规范（摘要）

来源：https://help.luogu.com.cn/rules/academic/solution-standard 。规范以官方页面为准，此处为写作时的速查摘要。

## 目录

- 基本规范
- 题解内容
- 排版
- 数学公式
- 图片与代码
- 提交与审核

## 基本规范

- 正确使用全角中文标点；句末要有句号。
- 数学公式（运算式、运算符、参与运算的常数、作为变量的字母）用 LaTeX；非数学内容（一般英文单词、题目名、算法名、人名）不用 LaTeX。
- 中文与英文、数字或公式之间以半角空格隔开；中文标点与英文、数字或公式之间不要有空格。

## 题解内容

- 只包含题目相关内容（题意简述、题目分析等）；不要闲聊、吐槽、加戏、求赞、求管理员通过、“蒟蒻的第一篇题解”。
- 题面较长时建议写题意简述，但不要把完整题面复制进来。
- 题目分析必须包含主要思路：用了什么算法或数据结构，以及对它的具体分析。
- 给出完整正确的解法与说明，对重要结论解释并证明；解法应能在合理复杂度内通过题目。
- 视频链接只能作补充，文字部分必须完整充分。
- 引用他人内容须不侵权，并用链接标注来源。
- 关键思路、论证过程、代码不得使用生成式 AI 辅助产生。使用生成式 AI 辅助写作（排版、润色）时，必须在文末或附录明确披露其具体贡献。

## 排版

- 用 Markdown 正确排版。
- 用 `#`、`##`、`###`、`####` 表示标题行；标题引导文章结构，不滥用于强调。
- 无序列表用 `-`、`+`、`*`，有序列表用 `1.`。
- 字符串或代码用行内代码，代码引用用行间代码块。
- 链接用 `[]()`，图片用 `![]()`。

## 数学公式

- 同一个公式写在同一个 LaTeX 环境内。
- 公式中的文本用 `\text`，字符串用 `\texttt`，如 `a \text{ is prime}`、`S = \texttt{aabcd}`。
- 独立成行的公式用 `$$...$$`。
- 用数学语言而非代码语言：
  - 赋值：`a \gets b` 或 `b \to a`，不写 `a = b;`。
  - 判定：用 `= \ne < \le > \ge` 和艾佛森括号 `[P]`。
  - 整除：`\lfloor \frac{a}{b} \rfloor`、`\lfloor a / b \rfloor`、`\lfloor a \div b \rfloor`，不用 `\frac{a}{b}` 或 `a/b` 直接表示整除。
  - 取模：`a \bmod b`；同余：`a \equiv b \pmod p`。
  - 不用 `a.b` 之类结构体写法，需要时用上下标。
  - 位运算：`\operatorname{and}`、`\operatorname{or}`、`\operatorname{xor}`。状压 DP 等用位运算实现集合运算的，建议直接用集合语言，如 `dp_{S \cup \{u\}} \gets dp_{S} + w_u`。
- 上下标：`a _ {b} ^ {c}`。
- 大数字用科学计数法：`5 \times 10 ^ 9`。
- 大 $O$ 记号中不带常数；值域、字符集大小等常量用字母表示。
- 运算符：`+ - \pm \times \cdot \div \le \ge \mid`。
- 约定俗成的函数名用正体：`\gcd \max \min \log \det`；未定义的用 `\operatorname`，如 `\operatorname{lcm}`。
- 大型运算符：`\sum \prod \bigcup \bigcap`，可能引起误解处加括号。
- 数学结构：`\frac{a}{b} \sqrt{a} \overline{a} \{a\}`。
- 箭头：赋值 `\to \gets`，因果 `\Leftarrow \Rightarrow`。
- 省略号：`\dots \cdots \ldots`；矩阵中其他方向用 `\vdots \ddots`。
- 波浪线：`\sim`。
- 连等式用 `aligned`，分段函数用 `cases`，矩阵用 `bmatrix`。

## 图片与代码

- 图片应简洁、清晰、美观，图中文字也要满足格式要求；不要引用带链接的图片。
- 配图原则上必须上传洛谷图床，避免外链；动图可用 Bilibili。
- 题解需附带代码；较短的题解在绝大多数情况下也应补充代码（哪怕只是核心片段），除非纯文字已足够清晰。
- 过长代码用折叠块（`:::info[标题]` … `:::`），不用云剪贴板。
- 代码应有一定可读性，可添加有意义的注释。
- 解法不能只在代码注释里描述，要在代码外用正常文字书写。
- 引用他人代码须不侵权，并用链接标注来源，位置建议放在代码之前。
- 不在代码中加入防抄袭内容。

## 提交与审核

- 在文章编辑页点击“提交题解”；提交前确保符合以上规范。
- 一般七天内审核，超过七天未审可私信管理提醒，七天内禁止催审。
- 被打回后按反馈修改；多次打回仍无实质修改会被封禁专栏权限。
- 题解数目较多的题目，管理员可能关闭提交通道；可提交全站推荐/题解工单并说明采纳理由。

## 洛谷 Markdown 扩展语法

来源：https://help.luogu.com.cn/rules/academic/handbook/markdown 。洛谷解析器遵循 CommonMark，支持 GFM 和下列扩展；原始 HTML 标签不会被解析，排版只能用 Markdown 或这些扩展。部分新特性在旧页面不显示，以编辑器预览为准。

- 折叠框：`:::info[标题]`、`:::success[标题]`、`:::warning[标题]`、`:::error[标题]`，以 `:::` 结束；加 `{open}` 默认展开（如 `:::info[标题]{open}`）；标题支持 LaTeX。嵌套时最内层三个冒号，每往外一层多一个冒号，应克制使用。
- 表格合并：单元格内容只写 `^`（向上合并）或 `<`（向左合并）。
- `::cute-table{tuack}`：Tuack 风格表格，紧跟一个普通表格，可配合合并语法，适合写数据范围表。
- 居中与居右：`:::align{center}`、`:::align{right}`，以 `:::` 结束。
- 引言：`:::epigraph[——署名]`，以 `:::` 结束。
- 任务列表：`- [ ]`、`- [x]`；自动链接：`<https://...>`。
- 代码块未指定语言时按 C++ 显示；仍应显式写 `cpp`。
- Bilibili 视频用图片语法插入。
